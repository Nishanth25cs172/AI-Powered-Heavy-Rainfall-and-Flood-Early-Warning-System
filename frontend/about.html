About the System

An AI-powered early-warning system for heavy rainfall and flood-risk assessment.

Project Overview

System purpose and key deliverables
🛡️ SYSTEM OVERVIEW & PURPOSE

The AI-Powered Heavy Rainfall & Flood Early-Warning System is an integrated decision-support platform designed to analyze rainfall patterns and environmental conditions in real time. By linking meteorological time-series observations with watershed hydraulic telemetry, the system delivers early predictions for extreme rainfall events and inundation hazards, helping emergency authorities take timely disaster mitigation measures.

Core System Deliverables:
  • Precipitation forecasting using historical Indian daily rainfall data (2009–2024).
  • Flood risk assessment and inundation probability calculation via Random Forest models.
  • Interactive GIS risk mapping across river basins and station coordinates.
  • Automated early warning bulletins, risk level ratings, and advisory guidelines.

Project Objectives

Core goals and functional scope
🎯 SYSTEM OBJECTIVES
1. Predict Rainfall Conditions
Utilize historical weather-related inputs and lag features to detect heavy rainfall events (≥ 64.5 mm threshold).
2. Assess Flood Risk
Evaluate environmental, geographical, and hydrological telemetry to estimate inundation likelihood.
3. Estimate Prediction Probabilities
Calculate calibrated statistical confidence percentages for both rainfall and flood hazards.
4. Convert to Risk Levels
Map raw probability scores into clear operational tiers: LOW, MODERATE, HIGH, and CRITICAL.
5. Provide Early Warnings
Generate actionable emergency advisories and evacuation recommendations for disaster response.
6. Simple User Interface
Present predictions, risk maps, and analytics through an intuitive, accessible web dashboard.

Official Datasets

Verified project data sources
📊 DATASET SPECIFICATIONS
1. Daily Rainfall Data - India (2009–2024)
Contains 204,876 daily records tracking historical precipitation, seasonal normals, and daily deviations across 36 Indian states and union territories. Used by the rainfall prediction module for time-series modeling.
Key Features: Date, State Name, Actual Rainfall (mm), Recent Rainfall (rfs), Climatological Normal (mm), Deviation (%), Lag 1, Lag 3, Lag 7, Day-of-Year Encoding, Monsoon Flag.
2. Flood Risk in India Dataset (flood_risk.csv)
Contains 10,000 station observations capturing environmental, geographical, hydrological, and infrastructure telemetry across Indian river basins. Used by the flood risk prediction module.
Key Features: Rainfall (mm), Temperature (°C), Humidity (%), River Discharge (m³/s), Water Level (m), Elevation (m), Latitude, Longitude, Land Cover, Soil Type, Population Density, Infrastructure, Historical Floods.

Machine Learning Models

Implemented models and performance metrics
🧠 AI / ML MODEL ARCHITECTURE
Rainfall Prediction Model: Random Forest Classifier Accuracy: 97.11%

Primary ensemble model (`rainfall_random_forest_model.joblib`) evaluating historical time-series lag features ($\text{Lag}_1, \text{Lag}_3, \text{Lag}_7$) and climatological normals to predict heavy rainfall ($\ge 64.5$ mm threshold).

Key Metrics: Accuracy: 97.11% | Recall: 81.36% | ROC-AUC: 98.40% | Precision: 11.12%
Flood Risk Model: Decision Tree Classifier Primary Classifier

Primary decision tree classifier (`flood_decision_tree_model.joblib`) evaluating 13 environmental and hydraulic features to predict watershed inundation (`Flood Occurred` YES/NO).

Evaluated Features: 13 Telemetry Attributes | Output: Inundation Probability & Risk Class
