⚙️ IMPLEMENTED PREPROCESSING
  • Missing Value Imputation: Climatological mean filling for `normal_filled`.
  • Categorical Encoding: One-Hot Encoding for state names and soil types.
  • Normalization & Scaling: Standard scaling for numeric features.
  • Chronological Train/Test Split: 2009–2021 (Train: 160,446) / 2022–2024 (Test: 27,268).
  • Zero Data Leakage Audit: Excluded `deviation` because actual rainfall is unknown at prediction time.
🔬 ENGINEERED MODEL FEATURES
  • Antecedent Precipitation Lags: `lag_1`, `lag_3`, `lag_7` days rainfall accumulation.
  • Cyclic Temporal Encodings: Day-of-Year sine/cosine harmonics (`sin_doy`, `cos_doy`).
  • Monsoon Seasonality Indicator: Binary monsoon flag (`is_monsoon`).
  • IMD Thresholding: Standardized 64.5 mm/day heavy deluge classification cutoff.
  • Watershed Factors: River discharge, water level stage, soil moisture %, slope, land cover.
